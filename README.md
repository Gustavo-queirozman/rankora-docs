# Rankora Docs

Documentación oficial de **Rankora**, un plugin premium para **WordPress** que utiliza **Inteligencia Artificial** para generar contenido optimizado para SEO de forma rápida, eficiente y escalable.

Rankora está diseñado para creadores de contenido, agencias de marketing, empresas y profesionales que desean automatizar la creación de artículos sin renunciar a la calidad ni a las buenas prácticas de posicionamiento en buscadores.

---

# 🚀 ¿Qué es Rankora?

Rankora es un plugin para WordPress que integra la API de OpenAI para ayudar a generar contenido de alta calidad directamente desde el panel de administración.

Su objetivo es reducir el tiempo dedicado a la creación de artículos, manteniendo una estructura optimizada para SEO y alineada con la intención de búsqueda de los usuarios.

La documentación de este repositorio explica cómo instalar, configurar y utilizar todas las funcionalidades disponibles.

# 🎯 Estrategia de Contenidos

Rankora permite generar contenido siguiendo estrategias de marketing digital basadas en el embudo de conversión.

### TOFU (Top of Funnel)

Contenido orientado a atraer nuevos visitantes mediante artículos informativos y educativos.

Ejemplos:

* ¿Qué es Laravel?
* Cómo mejorar el SEO de WordPress
* Guía para principiantes

---

### MOFU (Middle of Funnel)

Contenido pensado para usuarios que ya conocen el problema y están comparando soluciones.

Ejemplos:

* Laravel vs Symfony
* Los mejores plugins SEO
* Comparativa de herramientas

---

### BOFU (Bottom of Funnel)

Contenido enfocado en usuarios preparados para tomar una decisión de compra.

Ejemplos:

* Comprar Rankora
* Características Premium
* Casos de éxito

# 📦 Instalación

1. Descarga el plugin.
2. Accede al panel de administración de WordPress.
3. Ve a **Plugins → Añadir nuevo**.
4. Sube el archivo ZIP del plugin.
5. Activa Rankora.
6. Introduce tu licencia.
7. Configura la clave de OpenAI.
8. Guarda la configuración.

---

# ⚙️ Configuración Inicial

Una vez instalado el plugin:

* Introduce tu licencia.
* Configura la API de OpenAI.
* Selecciona el idioma predeterminado.
* Define el tono del contenido.
* Configura las opciones SEO.
* Guarda los cambios.

Después de estos pasos, Rankora estará listo para generar contenido.

---

# 🚀 Cómo generar un artículo

El flujo de trabajo es muy sencillo:

1. Introduce el tema principal.
2. Selecciona el idioma.
3. Elige la estrategia (TOFU, MOFU o BOFU).
4. Configura las opciones SEO.
5. Haz clic en **Generar**.
6. Revisa el contenido.
7. Publica el artículo.

# ❓ Preguntas Frecuentes

### ¿Necesito una licencia?

Sí.

Las funciones Premium requieren una licencia activa.

---

### ¿Necesito una clave de OpenAI?

Sí.

Rankora utiliza la API oficial de OpenAI para generar contenido.

---

### ¿Puedo usar la misma licencia en varios sitios?

No.

Cada licencia es válida para una única instalación de WordPress.

---

### ¿El contenido generado puede publicarse directamente?

Sí, aunque siempre se recomienda revisarlo antes de publicarlo para adaptarlo al estilo de la marca y verificar la información.

---

### ¿Rankora reemplaza a un redactor?

No.

Rankora es una herramienta de apoyo que acelera la creación de contenido. La revisión humana sigue siendo recomendable para garantizar calidad, precisión y coherencia editorial.
