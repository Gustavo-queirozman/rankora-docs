# Rankora Docs

Documentação oficial do **Rankora**, um plugin premium para **WordPress** voltado para **geração de conteúdo com inteligência artificial** e **otimização para SEO**.

## 📌 Sobre o projeto

O Rankora foi desenvolvido para auxiliar na criação de conteúdos de alta qualidade diretamente no painel do WordPress, combinando geração assistida por IA com recursos voltados para estratégias de SEO. A proposta do plugin é acelerar a produção de conteúdo, mantendo foco em estrutura, relevância e intenção de busca. :contentReference[oaicite:1]{index=1}

Este repositório concentra a **documentação oficial** do produto, incluindo instruções de instalação, ativação, configuração e uso.

## ⚙️ O que o Rankora oferece

- Geração de conteúdo com apoio de IA
- Integração com WordPress
- Configuração de idioma padrão
- Suporte a estratégia de conteúdo por funil:
  - **TOFU** (Top of Funnel)
  - **MOFU** (Middle of Funnel)
  - **BOFU** (Bottom of Funnel)
- Configurações de SEO integradas
- Fluxo de geração diretamente pelo painel administrativo do WordPress :contentReference[oaicite:3]{index=3}

## 🧩 Requisitos

Para utilizar o Rankora, é necessário:

- **WordPress 6.0 ou superior**
- **PHP 8.0 ou superior**
- **Chave válida da API da OpenAI**
- **Conexão ativa com a internet**
- **Licença ativa do Rankora** :contentReference[oaicite:4]{index=4}

## 🔐 Licenciamento

O Rankora exige **ativação por licença** para liberar os recursos premium. Segundo a documentação do projeto:

- cada licença é válida para **uma instalação WordPress**
- é necessária uma **assinatura ativa**
- ao cancelar ou expirar a assinatura, os recursos premium podem ser desabilitados :contentReference[oaicite:5]{index=5}

## 🚀 Como funciona

De forma geral, o fluxo de uso do plugin segue estas etapas:

1. Instalar e ativar o plugin no WordPress
2. Informar a chave da API da OpenAI
3. Definir idioma padrão
4. Escolher o tipo de conteúdo desejado
5. Configurar opções de SEO
6. Gerar, revisar e publicar o conteúdo :contentReference[oaicite:6]{index=6}

## ❓ FAQ resumido

### O plugin funciona sem ativar a licença?
Não. Sem ativação da licença, a geração de conteúdo e os recursos premium permanecem bloqueados. :contentReference[oaicite:9]{index=9}

### Posso usar a mesma licença em vários sites?
Não. Cada licença é limitada a uma instalação WordPress. :contentReference[oaicite:10]{index=10}

### O Rankora substitui redatores humanos?
Não. A própria documentação recomenda revisão humana do conteúdo gerado. :contentReference[oaicite:11]{index=11}

### O Rankora armazena dados pessoais?
A documentação informa que o plugin não armazena dados pessoais e que as ações são iniciadas pelo usuário. :contentReference[oaicite:12]{index=12}
